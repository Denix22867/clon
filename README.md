# Искра: путь героя

Браузерная idle/кликер-RPG на Godot 4.7.2 для Яндекс Игр.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `index.js`, `index.wasm`, `index.pck`, `*.js`, `*.css`, `*.png` | Готовая веб-сборка, как её прислали. Открывается через любой статический сервер. |
| `godot/` | Проект Godot, восстановленный из `index.pck`. Открывается в редакторе Godot 4.7. |
| `tools/decompile/` | Скрипты, которыми проект был восстановлен (можно перезапустить). |
| `blender/` | Все 3D-модели в `.glb` для Blender и инструкция, как вернуть их в игру. |
| `tools/export/` | Выгрузка процедурных моделей в `.glb`. |

## 2.5D-бой

Сцена боя (`godot/scripts/painted_world.gd`) — объёмные модели на нарисованном фоне:
перспективная камера чуть сверху, герой и враг стоят вполоборота, союзники в два ряда позади,
мягкие тени под ногами. Эффекты ударов рисуются в 2D по проекции 3D-точек.

| Файл | Что внутри |
|---|---|
| `godot/scripts/models/characters.gd` | Все модели: 7 героев (+ звёздный облик), 8 союзников, 10 врагов, рудная жила |
| `godot/scripts/models/mesh_kit.gd` | Инструменты моделирования из примитивов (кости, трубки, клинки, цепочки) |
| `godot/scripts/models/rig.gd` | Анимация: дыхание, плащи, хвосты, крылья, удары разных стилей, отдача |
| `godot/assets/models3d/*.gdshader` | Мультяшное освещение, обводка, мягкая тень |
| `godot/scenes/model_gallery.tscn` | Галерея всех моделей: откройте и запустите сцену (F6) |

Модели описаны кодом, а не файлами: у каждой кости один меш с цветом в вершинах, поэтому
персонаж рисуется за несколько вызовов и не добавляет веса к загрузке. Чтобы поменять внешность,
правьте параметры в `characters.gd` (цвета, причёска, оружие, плащ, рост, телосложение).

## Как восстанавливался проект

1. `index.pck` (формат PCK v4, без шифрования) распакован.
2. Скрипты `.gdc` (токенизированный GDScript, версия 101) раскодированы обратно в `.gd`.
   Комментарии в сборке не хранятся, поэтому их нет. Отступы, переносы строк и номера строк сохранены.
   **Проверка:** восстановленный код снова разбирается на токены, и поток токенов
   (типы, имена, литералы, номера строк) совпадает с оригиналом для всех 12 скриптов
   (32 408 токенов).
3. Текстуры `.ctex` → PNG без потерь (внутри был WebP lossless). Для атласов сохранены исходные `uid`.
4. Шрифты извлечены из `.fontdata` (`NotoSerif.ttf` побайтно совпадает с `loading-serif.ttf` сборки).
5. `project.godot` восстановлен из `project.binary`, `main.tscn` — по бинарной сцене (один узел `Iskra: Node3D`).

## Что отличается от оригинального проекта

- **Иконки интерфейса** (`assets/ui/*`) в оригинале были SVG; в сборке есть только растр 100×100,
  поэтому они лежат как PNG, а в `fantasy_main.gd` функция `icon()` грузит `.png` вместо `.svg`.
- **Плоские сцены боя** `mining.glb` и `painted_battle.glb` из оригинала заменены 2.5D-сценой (см. выше).
- Комментарии в коде утеряны при экспорте.

## Проверка в Godot 4.7.2

Проект импортирован и запущен в официальном Godot 4.7.2 (`ed1daf0bf`): все скрипты компилируются,
ошибок при запуске нет, игра проходит экран «Что нового», обучение и бой (рендер через Mesa/llvmpipe).

## Перезапуск восстановления

```bash
pip install zstandard pillow
python3 tools/decompile/gdre.py index.pck /tmp/out          # распаковка + декомпиляция
python3 tools/decompile/verify.py /tmp/out/raw /tmp/out/src # проверка токенов
python3 tools/decompile/build_project.py /tmp/out godot     # сборка проекта
```

## Экспорт в веб

В `godot/export_presets.cfg` есть пресет «Web» с `include_filter="web/*"`: файлы из `web/`
читаются через `FileAccess`, без этого фильтра они не попадут в `.pck`.
Обёртку страницы (загрузочный экран, реклама, обновления, защита от автокликера) берите из корня
репозитория: `bootstrap.js`, `platform.js`, `updater.js`, `guard.js` и т. д.
