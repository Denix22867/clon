# Модели для Blender

В `models/` лежат все 27 моделей игры в формате `.glb`, выгруженные из процедурного кода
(`godot/scripts/models/characters.gd`) скриптом `tools/export/export_glb.gd`.

| Файл | Кто |
|---|---|
| `hero_0_iskra`, `hero_0_iskra_star` | Искра (обычный и звёздный облик) |
| `hero_1_ice_sorceress` … `hero_6_dragon_knight` | Остальные 6 героев |
| `ally_0_fox` … `ally_7_spark_dragon` | 8 союзников |
| `enemy_m1_treant`, `enemy_0_goblin` … `enemy_8_root_king` | 10 врагов (номер = индекс рисунка в игре, `m1` = −1) |
| `ore_gold_vein` | Рудная жила для добычи |

## Как устроен файл

- **Кости — это объекты-пустышки** (Empty) с мешем внутри: `Hips`, `Torso`, `Head`, `ArmL`, `ArmR`,
  `LegL`, `LegR`, `Cape`, `Weapon`, `Pickaxe`, `Offhand`, `Tail`, `WingL`, `WingR` (у каждой модели свой набор).
  Анимация в игре вращает и сдвигает именно эти объекты (`godot/scripts/models/rig.gd`),
  поэтому **имена и иерархию нужно сохранить**. Скелета (Armature) нет: части жёсткие.
- **Поза покоя** — та, в которой лежат объекты. Удар рисуется поворотом `ArmR` вокруг оси «вперёд-назад»
  от плеча, поэтому точка начала (origin) каждой кости — это сустав (плечо, бедро, шея, основание хвоста).
- **Цвет** — атрибут вершин `Color` (в Blender: Color Attribute). Материал в игре всё равно заменяется
  мультяшным шейдером с обводкой, так что текстуры не нужны (но можно перейти на них — см. ниже).
- **Свечение** — координата U первой UV-развёртки: 0 = обычная поверхность, 1 = светится своим цветом
  (клинки, глаза, кристаллы).
- **Направление**: персонаж смотрит вдоль +X Godot. Импортёр glTF в Blender переводит оси сам;
  при обратном экспорте оставьте настройку «+Y Up» по умолчанию, и всё совпадёт.
- `Pickaxe` в игре скрыта и появляется только при добыче, `Weapon`/`Offhand` — наоборот.

## Как вернуть модель в игру

1. Отредактируйте модель в Blender (File → Import → glTF 2.0).
2. Экспортируйте в glTF Binary (`.glb`) с **тем же именем файла**. В настройках экспорта должны быть
   включены Mesh → UVs и Vertex Colors (Color Attributes).
3. Положите файл в `godot/assets/models3d/glb/`.
4. Запустите игру или галерею `godot/scenes/model_gallery.tscn` (F6): модель из файла заменит процедурную
   (`godot/scripts/models/overrides.gd`). Если файла нет — используется процедурная модель.

Рост подгоняется автоматически, так что масштаб в Blender не важен.

## Если захочется большего

- **Текстуры вместо цвета вершин** — потребуется добавить текстуру в шейдер `godot/assets/models3d/toon.gdshaderinc`.
- **Скелетная анимация** (Armature + клипы из Blender) — можно перейти на `AnimationPlayer` вместо
  процедурной `rig.gd`; тогда в файле должны быть клипы `idle`, `attack`, `hit`, а `painted_world.gd`
  будет их проигрывать.
